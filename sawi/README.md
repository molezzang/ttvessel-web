# 예비사위 검증소 (/sawi/)

딸이 데려온 예비 배우자에 대해 **결혼 전에 확인해야 할 것들**을 빠뜨리지 않게 도와주는
정적 웹앱. 의존성 없음(바닐라 JS), 서버 통신 없음.

## 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 7개 탭 레이아웃, 고지·면책 문구 |
| `style.css` | 디자인 시스템 (인쇄 스타일 포함) |
| `data.js` | 모든 문항·콘텐츠 데이터 |
| `app.js` | 렌더링·채점·저장 로직 |

## 탭
1. **빠른 진단** — 12문항 (역문항 2개)
2. **위험 신호** — 16항목 체크리스트 (치명 8 / 주의 8)
3. **심층 36문항** — 6영역 × 6문항
4. **질문 은행** — 8카테고리 64문항 (안심 답 / 체크 답 포함), 랜덤 3개 뽑기, 인쇄
5. **상황 관찰** — 10개 시나리오 × 관찰 포인트 3개
6. **서류 확인** — 10종 서류 가이드 + 위법한 뒷조사 경고
7. **결과 리포트** — 등급·레이더 차트·영역 막대·할 일, 채점자별 비교

## 채점
- 척도 4단계(0~3) + `모르겠다`(점수 제외, 별도 집계)
- `rev:true` 문항은 `3 - v`로 역채점
- 응답한 문항만으로 백분율 산출 → 주의 신호 1건당 -4점
- **치명 위험 신호가 1건이라도 있으면 최대 25점(E등급)으로 강제**하고 최상단에 경고 배너

## 저장
- 응답: `localStorage['sawi_state_v1']`
- 저장된 리포트: `localStorage['sawi_saved_v1']` (채점자별 비교용)
- 헤더의 `초기화` 버튼으로 둘 다 삭제

## 데이터 수정
문항 추가/수정은 `data.js`만 고치면 됩니다.
단, 심층 문항 수를 바꾸면 `app.js`의 진행률 상수(`QUICK.length + 36`) 2곳을 같이 고쳐야 합니다.

## 원칙 (수정 시 유지할 것)
- 판정 도구가 아니라 **대화 도구**라는 프레이밍
- 위험 신호는 유머 대상이 아님 — 실제 데이트폭력·강압적 통제 지표
- 서류 확인은 **본인 동의·상호 교환** 전제. 몰래 조회·흥신소 의뢰는 위법임을 명시
- 상담 창구(1366 / 112 / 1644-7077 / 1332) 노출 유지
