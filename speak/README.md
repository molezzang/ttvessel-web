# SPEAK LAB — 카메라 스피치 코칭

카메라 앞에서 연습하는 사람(아나운서·배우·발표자·선생님·면접 준비생)을 위한 자가 피드백 도구.
녹화한 영상에서 **시선·자세·제스처·표정·성량·억양·쉼·말속도·군말**을 뽑아, 선택한 카테고리 기준으로 채점하고 코멘트한다.

빌드 도구 없이 정적 파일 3개로 동작한다. `https://<도메인>/speak/` 로 열면 된다.

```
speak/
  index.html   화면
  style.css    스타일
  app.js       분석·채점·리포트 (ES 모듈, 의존성 없음)
```

## 어떻게 측정하나

| 신호 | 사용 API | 뽑아내는 지표 |
|---|---|---|
| 마이크 | Web Audio `AnalyserNode` | 성량 크기·성량 안정성(변동계수), 억양 폭(자기상관 F0의 반음 표준편차), 쉼 비율·긴 침묵 위치 |
| 받아쓰기 | Web Speech API (`ko-KR`) | 말속도(음절/분), 군말 빈도와 발생 시각 |
| 카메라 | MediaPipe **FaceLandmarker** | 정면 응시 비율, 시선 이탈 구간, 몸 흔들림(코 위치 분산 ÷ 얼굴폭), 미소 지수·표정 변화폭(블렌드셰이프) |
| 카메라 | MediaPipe **PoseLandmarker** (lite) | 어깨 수평(수평선 대비 각도), 제스처 활동량(손목 이동량 ÷ 어깨너비) |
| 녹화 | `MediaRecorder` | 다시보기·구간 이동·파일 저장 |

측정값은 **기준자세(캘리브레이션) 3초**를 기준으로 계산한다. 캘리브레이션을 건너뛰면
촬영 구간의 중앙값을 기준선으로 삼는다. 단, 어깨 수평만은 예외로 항상 **수평선(0°) 기준**이다 —
기울어진 자세를 기준으로 잡아 버리면 정작 잡아내야 할 문제가 상쇄되기 때문이다.

## 카테고리별로 채점이 다르다

같은 값이라도 직군에 따라 잘한 것일 수도, 못한 것일 수도 있다. 그래서 지표마다
**목표 구간(band)·한계선(hard)·가중치(w)** 를 카테고리별로 따로 둔다. (`CATEGORIES` in `app.js`)

- 억양 폭 6반음 → 배우 100점, 아나운서 20점
- 시선 고정 95% → 면접 100점, 배우 50점 (상대를 보지 않고 카메라만 보는 연기)

목표 구간 안이면 100점, 벗어나면 한계선(20점)까지 1.4승 곡선으로 떨어진다.
측정하지 못한 지표(마이크 무음, 음성인식 미지원, 모델 로드 실패)는 채점에서 빼고 나머지 가중치를 정규화한다.

기준값을 바꾸려면 `CATEGORIES[키].rubric` 의 `band`/`hard`/`w` 만 수정하면 된다.
가중치 합은 1이어야 하며, `band` 는 `hard` 안에, `hard` 는 `METRICS[키].scale` 안에 있어야 한다.

## 개인정보

- 녹화 영상, 대본, 채점 계산은 전부 브라우저 안에서만 처리된다. 업로드 경로 자체가 없다.
- 연습 기록(점수·지표만)은 `localStorage`에 남는다. 영상은 저장하지 않는다.
- **예외 하나**: ‘말속도·군말 인식’ 옵션은 브라우저 내장 음성인식을 쓴다. 크롬 등 일부 브라우저는
  이때 말소리를 제조사 서버로 보내 처리한다. 이 옵션을 끄면 전송되지 않고, 나머지 분석은 그대로 동작한다.

## 요구 사항

- Chrome / Edge 최신 버전 권장. `getUserMedia`는 **https 또는 localhost**에서만 동작한다.
- 얼굴·자세 모델은 첫 실행 시 CDN에서 약 4~10MB를 내려받는다(브라우저가 캐시한다).
  - 런타임: jsDelivr → unpkg 순으로 시도
  - 모델: `storage.googleapis.com/mediapipe-models`
  - 둘 다 막힌 환경이면 영상 분석만 빠지고 음성 분석·녹화는 정상 동작한다.
- 사내망 등에서 사본을 쓰려면 쿼리로 위치를 지정한다:
  `?mp=/vendor/tasks-vision&mpmodels=/vendor/models`
  (`mp` 아래에 `vision_bundle.mjs` 와 `wasm/`, `mpmodels` 아래에 `face_landmarker.task`,
  `pose_landmarker_lite.task` 가 있으면 된다.)

## 로컬에서 열기

```bash
npx http-server -p 8899 .     # 저장소 루트에서
# → http://127.0.0.1:8899/speak/
```

## 테스트

`window.__speaklab` 에 채점·분석 내부가 노출돼 있어 브라우저 콘솔이나 Playwright에서 바로 검증할 수 있다.

```js
const S = window.__speaklab;
S.bandScore(300, [250, 350], [150, 450]);   // 100
S.evaluate('interview', { eyeContact: 52, fillerRate: 5.4 });
```
