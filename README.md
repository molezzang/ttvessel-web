Google AdSense 승인을 목표로 설계한 정적(static) 콘텐츠 웹사이트입니다.

## 0. 먼저 읽어주세요 — "최근 3개월 승인 사이트 분석"에 대한 솔직한 안내

요청하신 "GitHub에서 최근 3개월 내 애드센스 승인받은 사이트 10개"는 **있는 그대로 찾는 것이 불가능**합니다.
이유는 다음과 같습니다.

- 애드센스 **승인 여부·승인 날짜는 공개되지 않는 비공개 정보**입니다. GitHub 저장소를 봐도
  "이 사이트가 언제 승인됐는지"는 알 수 없습니다. (코드에 `ca-pub-...` 광고 코드가 있어도
  그게 *승인된* 것인지, 신청만 한 것인지, 언제인지는 확인 불가)
- 따라서 "승인된 10개"라고 목록을 만들면 그건 **사실이 아닌 추정/창작**이 됩니다.
  그건 도움이 안 된다고 판단했습니다.

대신 **확실히 검증 가능한 것**으로 만들었습니다:
구글 애드센스 공식 정책 + 2025~2026년 승인 가이드 자료를 근거로,
**실제 승인되는 사이트들이 공통적으로 갖춘 구조**를 그대로 구현했습니다. (아래 1번 참고)

## 1. 애드센스 승인 사이트의 공통 구조 (이 사이트에 모두 반영함)

승인되는 콘텐츠 사이트들은 거의 예외 없이 아래 구조를 갖고 있습니다. 전부 구현되어 있습니다.

| 요소 | 왜 필요한가 | 이 사이트 |
|---|---|---|
| **About(소개) 페이지** | 운영 주체가 명확한 실체임을 증명 | `about.html` — 운영자 소개·전문성 |
| **Privacy Policy(개인정보처리방침)** | 애드센스 **필수**. 쿠키·광고 고지 포함해야 함 | `privacy.html` — 애드센스 쿠키 문구 포함 |
| **Terms(이용약관)** | 신뢰도 신호 + 의료 면책 | `terms.html` |
| **Contact(문의)** | 연락 가능한 실체임을 증명 | `contact.html` |
| **충분한 양질의 원본 글** | 핵심. 보통 800~1,000자+ 글 다수 권장 | 본문 8편(각 1,000자 이상, 원본) |
| **명확한 내비게이션/카테고리** | 사이트 구조가 정돈돼 보여야 함 | 상단 메뉴 + 홈 카드 그리드 |
| **저자 정보(E-E-A-T)** | 건강(YMYL) 주제는 **전문성 증명이 필수** | 17년차 방사선사 저자 명시 + 글마다 byline |
| **출처·면책 고지** | 의료 콘텐츠 거절 방지 | 모든 글에 출처 + 면책 박스 |
| **모바일 반응형 + 빠른 로딩** | UX 평가 | 프레임워크 없는 순수 HTML/CSS |
| **HTTPS + 독립 도메인** | 무료 서브도메인은 거절 위험 ↑ | 배포 시 적용 (아래 3번) |
| **sitemap.xml / robots.txt / ads.txt** | 색인·광고 인증 | 모두 포함 |

> ⚠️ **건강 주제(YMYL)는 양날의 검입니다.** CPC(광고 단가)는 높지만, 구글이 전문성·정확성을
> 더 까다롭게 봅니다. 그래서 이 사이트는 ① 실제 저자 경력 명시 ② 과장 주장 배제
> ③ 출처 표기 ④ "진단을 대체하지 않음" 면책을 **전 페이지에 적용**해 거절 사유를 원천 차단했습니다.
> 운영자님의 **17년 임상 경력은 다른 건강 블로그가 절대 못 따라오는 최고의 승인 무기**입니다. 적극 활용하세요.

## 3. 배포 방법 (무료, 30분)

애드센스는 **독립 도메인**을 강하게 권장합니다(`username.github.io` 같은 무료 서브도메인은 거절 위험).
추천 순서:

### A. GitHub Pages + 도메인 연결 (무료 호스팅)
1. GitHub에서 새 저장소 `ttvessel-web` 생성 → 이 폴더 전체 업로드
2. Settings → Pages → Branch `main` 선택 → 저장하면 `https://계정.github.io/ttvessel-web/` 로 공개
3. (권장) 도메인 구매 후 Pages의 Custom domain에 연결 → 자동 HTTPS

### B. 도메인 구매 (연 1~2만원)
- 가비아/후이즈/Cloudflare 등에서 `ttvessellab.com` 류 구매
- 코드 곳곳의 `https://www.ttvessellab.com/` 를 실제 도메인으로 일괄 치환
  (canonical, og, sitemap.xml, robots.txt 안의 주소)

### C. 대안 호스팅
- **Cloudflare Pages / Netlify / Vercel**: 폴더 드래그&드롭만으로 배포 + 무료 HTTPS. 더 쉽습니다.

## 4. 애드센스 신청 전 체크리스트

- [ ] 독립 도메인 + HTTPS 적용
- [ ] 글을 **최소 15~20편 이상**으로 늘리기 (지금 8편 → 아래 로드맵으로 확장)
- [ ] 각 글 본문 1,000자 이상, **본인이 직접 검토·수정**(AI 그대로 X — 경험·사례 추가)
- [ ] Google Search Console 등록 + sitemap.xml 제출 → 색인 확인
- [ ] 메뉴/푸터 링크 모두 정상 작동 확인
- [ ] 신청 후 광고 코드 삽입: `index.html` 상단의 주석 처리된 `<script>` 활성화 + `ads.txt`의 pub-ID 교체
- [ ] 신청 전 1~2주간 글을 꾸준히 올려 '활성 사이트'로 보이게 하기

> **팁:** 처음엔 글이 8편이라 조금 부족할 수 있습니다. 승인 확률을 높이려면 아래 로드맵에서
> **최소 7~12편을 더 채워 총 15~20편**으로 만든 뒤 신청하시길 권합니다.
> 각 글은 운영자님의 현장 경험 한두 문장만 더해도 'AI 티'가 사라지고 전문성이 확 올라갑니다.

## 5. 추가 콘텐츠 로드맵 (승인 확률 ↑, 심혈관 주제 22선)

이미 작성된 8편 외에, 같은 템플릿으로 복제해 채우기 좋은 고품질·고단가 주제들입니다.
(`posts/` 안의 글 하나를 복사 → 내용만 교체하면 동일 디자인으로 바로 추가됩니다.)

**검사·시술 (조영실 경험 살리기 — 차별화 최강)**
1. 심장 CT(관상동맥 석회화 점수) vs 조영술, 뭘 먼저?
2. 심전도(ECG) 결과지 읽는 법
3. 심초음파로 알 수 있는 것
4. 페이스메이커(인공심박동기) 환자 생활 가이드 ⭐
5. 관상동맥 우회수술 vs 스텐트, 어떻게 결정되나
6. 조영제 알레르기·신장, 검사 전 꼭 알아둘 것

**질환**
7. 협심증 vs 심근경색, 무엇이 다른가
8. 심부전 초기 신호와 관리
9. 부정맥 종류 총정리(서맥·빈맥·기외수축)
10. 대동맥류·대동맥박리 — 소리 없는 시한폭탄
11. 말초동맥질환(다리 혈관)과 걸을 때 종아리 통증
12. 뇌졸중 전조 'FAST' 기억법
13. 당뇨와 심혈관 합병증의 연결고리

**생활습관·예방**
14. 심장에 좋은 운동, 어떻게 얼마나
15. 돌연사를 부르는 습관 5가지
16. 겨울철 심근경색이 늘어나는 이유와 대비
17. 사우나·찬물 샤워, 심장에 괜찮을까
18. 음주와 심장 — '레드와인 한 잔' 진실
19. 스트레스·수면과 심장병
20. 갱년기 이후 여성의 심혈관 위험

**응급·실용**
21. 심폐소생술(CPR) & AED 사용법 ⭐ (생명 구하는 콘텐츠)
22. 우리 동네 응급실·심혈관센터 찾는 법 / 119 이용 팁

⭐ = 검색·공유가 특히 잘 되는 추천 우선순위
